## قاعدة البيانات (SQLite — v12)

| الجدول | الوصف |
|--------|-------|
| `products` | المنتجات (اسم، تصنيف، لون، مقاس، سعر بيع، سعر شراء، مخزون، باركود) |
| `product_barcodes` | باركودات متعددة لكل منتج |
| `categories` | التصنيفات (مكياج، عطور، عناية بالبشرة + مخصص) |
| `suspended_orders` | الفواتور المعلقة (التعليق) — مع الخصم |
| `suspended_order_items` | بنود الفواتور المعلقة |
| `sales` | فواتير المبيعات (إجمالي، أرباح، عدد القطع، خصم) |
| `sale_items` | بنود كل فاتورة بيع (اسم المنتج، الكمية، سعر الوحدة، سعر الشراء) |
| `settings` | إعدادات التطبيق key-value |
| `debts` | ديون الزبائن (اسم، هاتف، مبلغ، مسدد، ملاحظة، رابط فاتورة اختياري) |
| `debt_payments` | سدادات ديون الزبائن |
| `shop_debts` | ديون المحل (للموردين) |
| `shop_debt_payments` | سدادات ديون المحل |
| `expenses` | المصروفات (تصنيف، مبلغ، ملاحظة) |

**فهارس:** على الباركود، تواريخ المبيعات، تواريخ الديون، تواريخ المصروفات

## التنقل الأساسي (4 تبويبات)

```
الكاشير (pos_page) ← → المخزن (products_page) ← → المبيعات (sales_page) ← → الديون (debts_page)
```

- **صفحة المطور**: `Ctrl+Alt+Shift` ثم اكتب `devmh`
- **حماية الصفحات**: رموز PIN للمنتجات، المبيعات، الديون

## الميزات التفصيلية

### A. نقطة البيع (POS)
- شاشة مقسمة: سلة (يسار) + شبكة منتجات كروت (يمين)
- بحث بالاسم + فلتر بالتصنيفات (chips أفقية)
- ماسح باركود بالكاميرا (موبايل) + حقل باركود (لوحة مفاتيح)
- تعديل سعر البيع لكل منتج (الحد الأدنى = سعر الشراء)
- خصم لكل صنف على حدة (بالدينار)
- خصم على الفاتورة — مبلغ ثابت أو نسبة (قابل للتبديل)
- حماية المخزون — لا يسمح بالبيع السلبي
- **تنبيه المخزون المنخفض** — snackbar عند المسح + شارة بالشريط العلوي + حوار يعرض كل المنتجات المنخفضة (عتبة قابلة للتعديل من إعدادات المطور)
- تعليق واستئناف الفواتور (حفظ بالـ DB مع ملاحظة)
- حوار الدفع — حساب الفكة + خيار الطباعة
- طباعة الفاتورة على طابعة ثيرمال (PDF + QR Code)
- **طباعة على Isolate** — لا يقطع الـ UI
- طباعة مباشرة بدون حوار (طابعة افتراضية)
- إعادة طباعة آخر فاتورة

### B. إدارة المنتجات (المخزن)
- إضافة/تعديل/حذف المنتجات
- إدخال: اسم، تصنيف، لون، مقاس، سعر شراء، سعر بيع، مخزون، باركود
- **باركودات متعددة لكل منتج** — إضافة/تعديل/حذف
- توليد باركود محلي تلقائي (11 رقم)
- ماسح باركود في صفحة المنتجات للبحث
- إجمالي قيمة المخزون (رأس المال)
- إدارة التصنيفات — إضافة/تعديل/حذف من صفحة الإعدادات

### C. تقارير المبيعات
- فلتر زمني: اليوم / هذا الأسبوع / هذا الشهر / شهر مخصص / نطاق تواريخ / الكل
- بطاقات ملخص: الإيراد، تكلفة البضائع، المصروفات، الربح، صافي الكاش (لليوم + الكلي)
- شريط ملخص الفترة عند تفعيل الفلتر
- قائمة الفواتير مع عدد القطع وشارة الخصم والربح
- **عرض تفاصيل الفاتورة** — حوار سفلي مع كل المنتجات بالفاتورة
- **قيمة المخزون** = مجموع (المخزون × سعر الشراء)
- تصدير تقرير المبيعات لـ PDF

### D. مرتجعات المبيعات
- **إرجاع كامل** — حذف الفاتورة واستعادة المخزون بالكامل (معاملة واحدة)
- **إرجاع جزئي** — اختيار منتجات وكميات محددة للاستعادة
- تأكيد قبل التنفيذ
- المخزون يُستعاد تلقائياً
- يمكن الوصول من: صفحة المبيعات ← فاتورة ← حوار التفاصيل

### E. ديون الزبائن
- CRUD كامل (إضافة، تعديل، حذف)
- **سجل السداد** — كل دفعة مسجلة بتاريخها
- أزرار سداد سريع (نصف / الكل)
- حوار تفاصيل الدين — إجمالي/مدفوع/متبقي + حالة + ملاحظة + تواريخ + سجل الدفعات
- فلاتر: غير مسدد / مسدد / الكل
- بطاقة ملخص: الإجمالي + المدفوع + المتبقي + العدد
- **تصدير PDF** + **تصدير CSV**

### F. ديون المحل (موردين)
- CRUD كامل ل凫 شكل mirrors דיוני الزبائن
- سجل السداد مع التواريخ
- تصدير PDF + CSV

### G. المصروفات
- 9 تصنيفات: يوميات، مشتريات، إيجار، رواتب، فواتير، صيانة، نقل وشحن، إعلانات، أخرى
- إضافة/حذف مع تصنيف ومبلغ وملاحظة
- تجميع حسب اليوم مع مجموع كل يوم
- بطاقة ملخص: مصروفات اليوم + إجمالي + عدد
- **طباعة تقرير PDF** — مجمّع حسب الأيام

### H. تقرير نهاية اليوم (Z-Report)
- إيراد المبيعات vs المصروفات
- صافي الكاش (شريط كبير)
- عدد المبيعات + القطع المباعة + الربح
- الديون المسددة اليوم (زبائن + محل)
- أفضل 5 منتجات مبيعاً مع الكمية والإيراد
- **طباعة PDF**
- الوصول من: إعدادات المطور ← التقارير

### I. النسخ الاحتياطي
- نسخ احتياطي لمجلد مخفي (`D:\.lamsa_backup` على ويندوز)
- نسخ بأسماء موقّتة
- **عرض قائمة النسخ المحفوظة** + استعادة منها
- **استيراد من ملف .db خارجي** (عبر file_picker)
- WAL checkpoint قبل النسخ لضمان التكامل
- زر النسخ موجود بالصفحة المخفية + صفحة المبيعات

### J. إعدادات المطور (صفحة مخفية)
- **بيانات المحل**: اسم، هاتف، عملة
- **إدارة التصنيفات**: إضافة/تعديل/حذف (حماية من الحذف إذا فيه منتجات)
- **إعدادات المخزون**: عتبة تنبيه المخزون المنخفض
- **إعدادات طباعة الفاتورة**: نسخ الباركود الافتراضية، نص تذييل الفاتورة، رابط QR Code، أحجام الخطوط، عرض الورق، هوامش الطباعة (أعلى/أسفل/يسار/يمين)
- **إعدادات طباعة الباركود**: عرض/ارتفاع البطاقة، الحشو (أعلى/أسفل/يسار/يمين)
- **إعدادات الطابعات**: طابعة الفاتورة + طابعة الباركود (مستقلتان)
- **حماية PIN**: تعيين/مسح رموز للمنتجات، المبيعات، الديون (SHA-256)
- **النسخ الاحتياطي والاستيراد**
- **رابط Z-Report**

### K. نظام حماية PIN
- رموز منفصلة لكل صفحة: المنتجات، المبيعات، الديون
- تشفير SHA-256 — لا يُخزّن كنص واضح
- فتح الجلسة — يبقى مفتوحاً حتى إعادة التشغيل
- صفحة مطور مخفية — `Ctrl+Alt+Shift` ثم `d e v m h`

### L. نظام الإشعارات
- **4 إشعارات منفصلة**: `productsRevision`، `salesRevision`، `debtsRevision`، `expensesRevision`
- كل صفحة تسمع فقط لتغييراتها
- **Offstage** — تبديل أخف من IndexedStack

### M. سجل الأخطاء
- ملف مخفي `%APPDATA%/AHLA_logs/app_log.txt`
- يسجل INFO + ERROR مع التواريخ والأstack traces
