# تفعيل تشفير قاعدة البيانات (SQLCipher)

التطبيق يدعم تشفير كامل لقاعدة البيانات على القرص. التشفير **معطّل افتراضياً**
ويعمل التطبيق بشكل طبيعي بدونه.

## كيف تفعّل التشفير؟

1. حمّل SQLCipher لنظام Windows (نسخة x64):
   - من الموقع الرسمي: https://github.com/sqlcipher/sqlcipher/releases
   - أو نسخة مجمععة من: https://www.zetetic.net/sqlcipher/open-source/

2. خذ ملف `sqlcipher.dll` وضعه **بجانب ملف `lamsa.exe`**:
   ```
   C:\Program Files\أحلى الحلوين\
   ├── lamsa.exe
   ├── sqlcipher.dll   ← هنا
   ├── sqlite3.dll
   └── data\...
   ```

3. شغّل التطبيق. عند أول فتح للقاعدة:
   - إذا كانت القاعدة نصية (غير مشفرة) → **تُشفَّر تلقائياً** في مكانها
   - المفتاح يُولَّد عشوائياً ويُحفظ في `%APPDATA%\Lamsa\.dbkey` (ملف مخفي)

## ⚠️ تحذيرات مهمة

| القاعدة | التفصيل |
|---------|---------|
| **لا تحذف ملف المفتاح** | `%APPDATA%\Lamsa\.dbkey` — بدون النسخ الاحتياطية **لا يمكن فتحها نهائياً** |
| **النسخ الاحتياطية مشفرة** | أي نسخة تُنشأ بعد التفعيل تكون مشفرة — تحتاج نفس المفتاح |
| **نسخ قديمة قبل التشفير** | تبقى نصية وتشتغل، وعند استيرادها **تُشفَّر تلقائياً** |

## كيف تتأكد أن التشفير يعمل؟

افتح سجل الأخطاء `%APPDATA%\AHLA_logs\app_log.txt`:

- ✅ مفعل: لا يوجد تحذير عن sqlcipher، وترحيل "تم تشفير قاعدة البيانات"
- ❌ معطل: تجد `"WARNING": "التشفير غير مفعّل"`

## إزالة التشفير (إذا احتجت)

احذف `sqlcipher.dll` من مجلد التطبيق + افتح النسخة الاحتياطية الأحدث
(النصية) عبر زر الاستيراد — ستعود القاعدة نصية.
